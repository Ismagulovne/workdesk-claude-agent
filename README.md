# WorkDesk+Claude — агент для компьютера

Дает приложению WorkDesk на телефоне доступ к Claude Code на этом компьютере через сервер WorkDesk
(workdesk.kz). Claude Code работает под вашим аккаунтом Claude; агент и сервер WorkDesk учетные данные Claude не видят.

## Установка

1. Установите Claude Code и войдите своим аккаунтом: `claude`, затем `/login`.
2. Скачайте `workdesk-claude` для своей системы со страницы загрузок WorkDesk.
3. Привяжите компьютер к учетной записи WorkDesk (ID берется из установленного клиента WorkDesk):
   `workdesk-claude login`
4. Запустите: `workdesk-claude run` — компьютер появится во вкладке «Claude» в приложении WorkDesk на телефоне.

Доступ Claude к другим устройствам WorkDesk (по ID, через режим `WorkDesk --mcp`) включается флагом
`workdesk-claude run -workdesk auto` или `-workdesk <путь к WorkDesk>`. Нужен клиент WorkDesk с поддержкой `--mcp`:
агент проверяет это при запуске и со старым клиентом режим не включает.

Телефон видит только компьютеры своей учетной записи. Действия, которые требуют разрешения
(команды, изменение файлов), Claude выполняет только после подтверждения на телефоне.

Протокол: `console/docs/CLAUDE_RELAY.md` в репозитории WorkDesk. Лицензия: AGPL-3.0.
